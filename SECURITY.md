# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 1.x     | Yes       |

## Reporting a vulnerability

Please report security problems privately by email to **info@ligatrix.com**. Do not open a public issue.

Include:

- the affected version and Node.js version;
- a description of the problem and its impact;
- steps or a minimal script to reproduce it;
- any suggested fix, if you have one.

We acknowledge every report within 2 business days, keep you informed while we work on a fix, and credit you in the release notes if you wish.

Signature verification (`src/signature.js`) and path reading (`src/paths.js`) are the most security-sensitive parts of this library; reports about them are especially welcome.
